**[golemcloud/golem](https://github.com/golemcloud/golem)** — Distributed WebAssembly agent platform, Rust.
Standalone server. Example: [handling SIGINT/SIGTERM](https://github.com/golemcloud/golem/pull/3799).

**[astral-sh/ruff](https://github.com/astral-sh/ruff)** — Python linter, Rust.
When a fix is safe enough to apply unasked. Example: [`FURB101`/`FURB103` with a file descriptor](https://github.com/astral-sh/ruff/pull/27643).
[Merged](https://github.com/search?q=repo%3Aastral-sh%2Fruff+is%3Apr+author%3Abaltasarblanco+is%3Amerged&type=pullrequests)

**[coredns/coredns](https://github.com/coredns/coredns)** — DNS server, Go.
Cache and file plugins. Example: [resolving each additional-section target once](https://github.com/coredns/coredns/pull/8286).
Credited in the v1.14.5 and v1.14.7 release notes.
[Merged](https://github.com/search?q=repo%3Acoredns%2Fcoredns+is%3Apr+author%3Abaltasarblanco+is%3Amerged&type=pullrequests)

**[swc-project/swc](https://github.com/swc-project/swc)** — JS/TS compiler, Rust.
